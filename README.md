# To-Do App ✅

A multi-user To-Do application with authentication, built with Streamlit, PostgreSQL (Supabase) and SQLAlchemy.

## Features (planned)
- User registration & login (bcrypt)
- Per-user task isolation
- Task CRUD (create, read, update, delete)
- Priority levels, due dates, completion status
- Filtering & search
- Statistics dashboard

## Tech Stack (planned)
- Python 3.11+
- Streamlit
- SQLAlchemy 2.0
- PostgreSQL (Supabase)
- passlib + bcrypt
- pytest
